# Find My Home · GURU
An English-only speaking game for There is / There are, with ten illustrated cutaway houses and photorealistic fictional characters.
Open index.html in a browser, or run node server.mjs.
Each of ten stories reveals two client wishes gradually. Describe a home aloud, then click Check this home. A suitable first choice unlocks the next fact. The final home must fit both wishes. Wrong choices can be retried. No typing, microphone or speech recognition is used; spoken accuracy is checked by the learner or teacher. Optional example statements and browser text-to-speech are included.
Run node build.mjs after source changes. Run node --test tests/*.test.mjs to check the story flow.
To share the game, keep index.html, styles.css, standalone.js and assets/ together.
